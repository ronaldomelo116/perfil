# 💻 Dev Profile & Skills | Ronaldo Melo

Uma página de perfil pessoal e portfólio desenvolvida com foco em demonstrar competências técnicas, stack de desenvolvimento e trajetória profissional em transição de carreira para a área de tecnologia.

O design possui uma estética moderna inspirada em editores de código (tema Dracula) e janelas de terminal, utilizando a tipografia *Fira Code*.

## ✨ Funcionalidades

- **Design Dark Mode Inspirado no Dracula:** Paleta de cores moderna com variáveis CSS personalizadas (`--fundo-bg`, `--nome-var`, etc.).
- **Estética de Terminal / Editor:** Botões de controle de janela macOS (*window dots*) e tipografia monoespaçada (*Fira Code*).
- **Interatividade & Efeitos:** Efeito *hover* com elevação e brilho suave (*drop-shadow*) nos ícones de tecnologias.
- **Responsividade:** Layout adaptável via Flexbox e Media Queries para uma ótima experiência em desktops, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização moderna, variáveis CSS, Flexbox, transições e responsividade.
- **Bootstrap 5 & Bootstrap Icons:** Ícones vetoriais e utilitários.
